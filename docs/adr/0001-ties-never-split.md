# Tied observations are never split across classes

Classes are upper-inclusive intervals (`bins[j-1] < y <= bins[j]`), so observations with equal values always land in the same class. We keep this as a hard invariant for every classifier, even when it makes quantile-style classes unequal in size or reduces the number of classes below the requested k. The alternative — spreading a block of tied values across classes to balance counts — would make class membership depend on row order rather than on the attribute value, which is indefensible on a map where two areas with the same value must get the same colour. Consequences: k can never exceed the number of distinct values, breaks fall only on observed values or midpoints between distinct values, and a fitted classifier reports the k it actually produced.
